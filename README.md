# Carrefour CRM Campaign Analysis

## Project Overview

This project analyzes CRM email campaign performance using SQL and SQLite. The analysis focuses on campaign-level performance metrics, with particular attention to French newsletter campaigns.

The objective is to evaluate campaign effectiveness, compare campaign versions, and generate KPI-driven business insights to support marketing decision-making.

## Business Objectives

- Explore and understand CRM campaign data.
- Analyze email campaign performance across different campaign categories.
- Identify high-performing campaigns using key performance indicators.
- Evaluate French newsletter campaign performance.
- Compare different versions of the `fr_news_extreme` campaign.
- Translate analytical findings into actionable business insights.

## Dataset Description

The dataset is stored in the `crf_email_campaign` table and contains 80 records.

| Column | Description |
|---|---|
| `id` | Unique record identifier |
| `campaign_id` | Campaign identifier |
| `campaign_title` | Campaign name |
| `send_count` | Number of emails sent |
| `open_count` | Number of emails opened |
| `click_count` | Number of clicks |
| `revenue` | Revenue generated by the campaign |

## Key Performance Indicators (KPIs)

Four key metrics were calculated to evaluate campaign effectiveness.

| KPI | Formula |
|---|---|
| Opening Rate | Open Count / Send Count |
| Click Rate | Click Count / Send Count |
| CTR | Click Count / Open Count |
| Revenue per Mille | (Revenue / Send Count) × 1,000 |

## Key Findings

### French Newsletter Campaign Analysis

The analysis identified differences in engagement and revenue performance across French newsletter campaigns.

The `fr_news_extreme` campaign generated the highest sending volume among the compared campaign versions.

### Campaign Version Comparison: fr_news_extreme

Four campaign versions were compared using the same KPI methodology.

| Campaign ID | Opening Rate | Click Rate | CTR | Revenue per Mille |
|---|---:|---:|---:|---:|
| 3002 | 24.62% | 3.23% | 13.13% | 123.08 |
| **3003** | **24.80%** | **3.28%** | **13.23%** | **124.00** |
| 3004 | 24.44% | 3.19% | 13.03% | 122.22 |
| 3005 | 24.61% | 3.24% | 13.17% | 123.44 |

**Best-performing version: Campaign ID 3003**

Campaign 3003 achieved the highest performance across all four KPIs, despite having the lowest sending volume among the four versions.

## Business Insights

- Campaign performance should be evaluated using multiple KPIs rather than sending volume alone.
- Engagement metrics provide insights into how effectively campaigns attract and activate recipients.
- Revenue per mille helps assess the revenue generated relative to campaign reach.
- Campaign version comparisons can support data-driven decisions when optimizing future marketing activities.
- KPI results should be interpreted alongside campaign volume and data completeness.

## Project Outcome

This project demonstrates the use of SQL for CRM data exploration, campaign performance measurement, KPI calculation, and comparative analysis.

The findings provide a foundation for data-driven marketing decisions and campaign optimization.
